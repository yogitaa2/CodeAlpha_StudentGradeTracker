# Student Grade Tracker

A console-based Java application for inputting, managing, and analyzing student grades.

## Features

* Input the number of students.
* Enter student names and marks.
* Store student data using `ArrayList`.
* Calculate average marks.
* Find the highest marks and corresponding student.
* Find the lowest marks and corresponding student.
* Validate marks between 0 and 100.
* Display a summary report of all students.

## Technologies Used

* Java
* ArrayList
* Scanner
* Console Interface

## Project Requirements

* Input and manage student grades.
* Calculate average, highest, and lowest scores.
* Use `ArrayList` to store and manage data.
* Display a summary report of all students.
* Use a console-based interface.

## How to Run

### Compile

```bash
javac StudentGradeTracker.java
```

### Run

```bash
java StudentGradeTracker
```
